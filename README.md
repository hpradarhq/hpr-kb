# HPR Knowledge Base

Persistent, version-controlled canonical knowledge distilled from project conversations and other authoritative sources.

## Model

- `raw/` — immutable historical evidence when an authoritative source is available.
- `kb/` — distilled canonical state organized by durable Knowledge Streams.
- `meta/` — KB schema and conventions.
- Git history — provenance and evolution.

Do not treat chat sessions as documents or single topics. New evidence is semantically routed into existing Knowledge Streams, with brainstorming kept separate from canonical decisions.
